# AI-Powered Business Intelligence & Decision System

## Project Overview

This project demonstrates an end-to-end Business Intelligence
and Decision Support System for a fictional retail company.

The system combines:

- SQL
- Excel
- Python
- Power BI
- Generative AI
- Business Analysis
- Automation

## Business Objective

Help management understand sales performance,
profitability, customer behavior, and regional performance,
and convert data into actionable business recommendations.

## Project Pipeline

Raw Data
→ Data Cleaning
→ SQL Database
→ SQL Analysis
→ Power BI
→ Python Analytics
→ GenAI
→ Business Recommendations
→ Automation
